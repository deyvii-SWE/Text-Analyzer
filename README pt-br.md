# Text Analyzer

## Como Funciona

Você pode digitar ou colar um texto no programa, e ele irá analisá-lo contando o número total de palavras e caracteres, tanto com quanto sem espaços. Ele também identifica a palavra mais utilizada e calcula o tamanho médio das palavras.

É um projeto simples, criado principalmente para praticar alguns conceitos de Python e experimentar diferentes funcionalidades.

## Sobre o Código

Não tenho muito a dizer sobre esse código. Utilizei uma classe para organizar a interface e uma função separada para analisar o texto e calcular suas estatísticas.

A função retorna todos os resultados em uma lista, então basta chamá-la, armazenar os valores retornados e passá-los para a interface exibir tudo.

Também utilizei o `Counter`, do módulo `collections` do Python, para identificar a palavra mais utilizada.

No geral, foi um projeto curto e divertido para continuar praticando e manter minha atividade no GitHub!
