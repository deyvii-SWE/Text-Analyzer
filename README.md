# Text Analyzer

## How It Works

You can type or paste a text into the program, and it will analyze it by counting the total number of words and characters, both with and without spaces. It also identifies the most frequently used word and calculates the average word length.

It's a simple project, mainly created to practice some Python concepts and experiment with different features.

## About the Code

I don't have much to say about this code. I used a class to organize the interface and a separate function to analyze the text and calculate its statistics.

The function returns all the results in a list, so I just call it, store the returned values, and pass them to the interface to display everything.

I also used Python's `Counter` from the `collections` module to identify the most frequently used word.

Overall, it was a short and fun project to keep practicing and maintain my GitHub activity!
